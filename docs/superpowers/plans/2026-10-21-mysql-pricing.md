# 报名价格持久化与紧凑布局实施计划

**目标：** 将报名价格保存到 MySQL，修复已确认的价格一致性与编辑问题，并让后台价格矩阵完整展示。

**架构：** 新增 `registration_pricing` 表，按活动保存完整价格矩阵和版本号。价格仓储通过既有数据库接口读取配置，在事务内校验版本、更新配置并写入操作历史。公共套餐接口与报名事务读取该配置，不修改进程共享的默认套餐；历史订单继续使用已有快照。

**技术：** Node.js、MySQL 8、现有原生 HTML/CSS 与 `node:test`。保留未提交改动，不执行提交、推送或生产迁移。
