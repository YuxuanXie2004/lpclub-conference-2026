# 参会资料页面改版

目标：统一首次报名与邮件补交资料的展示方式，采用简约品牌样式，将展示授权放在对应照片与 Logo 旁边，并保留一个最终确认入口。

设计：复用现有绿色 LP CLUB Logo。使用品牌深绿 #1e3529、正文 #22302a、次级文字 #65746c、分隔线 #dce5df、背景 #f4f7f5 与白色 #ffffff；异常提示使用深红。标题沿用官网无衬线风格，正文使用系统中英文字体。资料采用纵向清单，每项包含缩略图、用途、明确状态及选图入口，手机端自然堆叠。

- [x] 将用户补交页模板与后台模板隔离，保留 fragment 清理、请求头认证及私有图片预览。
- [x] 隐藏用户不需要的文件版本号，显示可读套餐名称和明确的重交原因。
- [x] 选择图片后仅创建本地预览，确认前允许取消或更换。
- [x] 照片授权放在照片资料项内，机构授权放在 Logo 资料项内；普通参会不显示肖像上传及其授权。
- [x] 补交页使用底部唯一的“确认保存”按钮，一并提交图片与授权；只修改授权也能确认保存。
- [x] 部分保存失败时保留未完成草稿，明确说明结果并支持重试；已保存图片无需重复选择。
- [x] 官网首次报名资料区同步改为清单，分别解释用途、图片要求、展示条件和邮件补交方式。
- [x] 必填的报名确认与隐私说明位于全部资料之后，仍由原有“提交报名”按钮统一提交。
- [x] 页脚自然跟随内容；资料区不继承官网大段落的底部留白；英文选图按钮保持单行。
- [x] 检查中英文与电脑、平板、手机布局，运行相关测试和差异检查。

范围：用户页面、样式及脚本。保留现有文件、授权、报名及邮件接口，不修改数据库结构、后台审核规则、生产配置或凭据；不新增依赖。
